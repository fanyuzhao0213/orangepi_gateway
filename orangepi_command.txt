参数	全称	含义
dtc	  	Device Tree Compiler	设备树编译器，用于将文本格式的设备树源文件转换为二进制格式
-@	   	symbol support	启用符号支持，使得编译出的文件支持动态叠加（overlay）
-I dts	Input format = dts	指定输入文件格式为设备树源文本格式（.dts）
-O dtb	Output format = dtb	指定输出文件格式为设备树二进制格式（.dtb）
-o orangepi2w-led.dtbo	output file	指定输出文件名为 orangepi2w-led.dtbo
orangepi2w-led.dts	输入源文件	待编译的设备树源文件
